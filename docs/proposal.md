# 음악 공유 플랫폼 기획서

## 1. 프로젝트명 및 한 줄 서비스 소개

### 프로젝트명 : Tuna

**본인 취향의 음악과 짧은 감상평을 올리고, 댓글로 서로 소통하는 음악 공유 서비스입니다.**

---

## 2. 프로젝트 기획 배경 및 목적

### 2.1 기획 배경

  오늘 날의 디지털 음원 시장은 숏폼 콘텐츠와 알고리즘 추천을 중심으로 하루가 멀다하고 트렌드가 급변하고 있습니다.  수많은 신곡들이 매일 쏟아져 나오고 있지만, 역설적으로 이용자들은 차트 상위권 음악이나 알고리즘이 정해준 수동적인 틀 안에서만 음악을 소비하게 되는 한계에 머물러 있습니다. 이에 따라 나도 모르는 숨겨진 곡들이나 자신의 진짜 취향에 맞는 새로운 음악을 발견 할 수 있는 계기가 될 수 있었으면 합니다.

  또한, 요즘 MZ세대를 중심으로 한 음악 소비자들에게 음악은 단순한 청각적 감상을 넘어 자신의 정체성과 취향을 대변하는 핵심 매개체로 자리 잡았습니다. 내가 들었던 음악, 나만 알고 싶은 아티스트, 특정 순간에 느꼈던 감정을 기록하고 공유하는 행위는 강력한 자기 표현의 방식입니다. 그러나, 기존의 대형 음원 플랫폼은 일방향적인 감상 환경만을 제공하여, 음악을 매개로 타인과 깊이 공감하고 이야기를 나누기에는 커뮤니티적 요소가 부족합니다. 

### 2.2 프로젝트 목적

 본 플랫폼은 매일 업데이트되는 트렌드 속에서 사용자들이 직접 서로의 유일무이한 음악 플레이리스트와 추천곡을 공유하는 커뮤니티 공간을 제공하고자 합니다. 사용자는 이곳에서 자신만의 독창적인 음악적 취향을 자유롭게 표출하고 이야기하며, 타인의 추천을 통해 알고리즘 너머의 새로운음악을 지속적으로 발견하는 즐거움을 경험하게 됩니다.

## 3. 서비스 주요 특징

### 링크로 음악 공유

사용자는 음원파일 대신에 음원URL을 첨부합니다. 해당 링크를 누르면 해당 음원을 들을 수 있는 외부 사이트로 이동합니다. 

### 짧은 글 중심

긴 음악 리뷰는 필요 없습니다. 추천 이유나 감상을 짧게 적으면 됩니다.

### 피드 방식

게시글은 최신순으로 보여줍니다. 복잡한 메뉴는 줄이고 게시글을 빠르게 보는 데 집중합니다.

## 4. 주요 도메인 기능

### 회원 시스템

- 회원가입
    - 사용자가 회원가입을 하면 회원 생성
    - 중복된 이메일이 있을 경우엔 회원가입 불가
- 로그인(signin)
    - 회원가입 하지 않는 사용자는 로그인이 불가능함
    - 사용자가 로그인을 하면 세션 추가
- 로그아웃 기능
    - 사용자가 로그아웃을 하면 세션 삭제

### 게시글 시스템

- 사용자가 자신이 쓴 게시글일 경우 생성/수정/삭제 할 수 있음
- 게시물 방문시 조회수 카운트 증가
- 사용자가 자신이 선호하는 게시물에 추천 버튼을 눌러 추천 카운트를 늘릴 수 있음
    - 사용자는 게시물 하나에 한번의 추천만 가능, 추천 취소 불가
- 게시물 목록은 10개의 페이징리스트로 조회
- 특정 키워드로 일치하는 게시물 제목 또는 내용 검색

### 댓글 시스템

- 사용자가 게시물에 댓글을 생성/수정/삭제
- 게시물 삭제시 게시물과 연결된 댓글 삭제

### 플레이리스트 시스템

- 사용자가 플레이리스트를 생성/삭제
- 플레이리스트에 게시물을 추가/제거
- 게시물 삭제시 플레이리스트 목록에서도 제거

### 마이페이지

- 마이페이지 클릭시 자신이 작성한 게시물들을 10개의 페이징리스트로 조회

### 공통

- 사용자를 관리자, 일반회원 으로 구분
    - 일반회원의 경우 자신의 게시글, 댓글, 플레이리스트 수정/삭제 가능
    - 관리자의 경우 타인의 게시글, 댓글을 수정/삭제 가능

## 6 팀 구성 및 도메인별 역할 분담표

- 회원
    - 회원가입: 김두희
    - 로그인/로그아웃: 이수환
- 게시글
    - 게시글 CRUD: 정승우
    - 페이지네이션, 검색, 조회수, 추천:  이원준
- 댓글
    - 댓글 CRUD 및 접근 권한: 한나라
- 플레이리스트
    - 생성, 등록/삭제, 수정, 제거: 이원준

## 7. 시스템 아키텍처 구상

**1. 클라이언트 계층 (Presentation Layer)**
- HTML5, CSS3, JavaScript
- Thymeleaf Template Engine (Server-Side Rendering)

**2. 애플리케이션 계층 (Application Layer)**
- Spring Boot Web (Spring MVC)
- Spring Security를 이용한 세션 기반 로그인 인증 및 URL 패턴별 인증 체크
- Controller / Service / Repository 계층 분리 3-Tier Layered Architecture

**3. 데이터 계층 (Data Layer)**
- Spring JDBC (JdbcTemplate 기반 데이터 접근 및 RowMapper 데이터 매핑)
- MySQL Database
